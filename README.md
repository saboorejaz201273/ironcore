# IronCore Fitness (React + Vite)

## Run locally
```
npm install
npm run dev
```
Build: `npm run build` | Preview: `npm run preview`

## Kahan kya change karein
- Sab content `src/data.js` mein: BRAND, CONTACT, SOCIALS, IMAGES, SERVICES, PLANS (prices), TRAINERS, TESTIMONIALS
- Colors/fonts: `src/index.css` (`:root` variables) aur Google Fonts link in `index.html`
- Contact form demo hai: `src/components/Contact.jsx` ke `submit` mein backend/email service connect karein
